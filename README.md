# Carvalhokids

## Descrição

A carvalho kids é um site de aluguel de um pequeno aluguel de brinquedos.

## Objetivo

O objetivo do site será divulgar e fornecer brinquedos, trazendo uma maneira mais fácil para que as pessoas possam aluga-los.

## Tecnologias Utilizadas

**Frontend**
- HTML
- CSS
- Bootstrap
- Chat gpt
- manual IA

## Funcionalidades
- Tela de seleção da versão do site.
- Apresentação da empresa.
- Apresentação de brinquedos.
- Como funciona (o aluguel dos brinquedos).
- Uma área para as pessoas entrarem em contato.

## Estrutura do Projeto

- **Pasta projeto-carvalhokids:** arquivos das apinas geradas po ia incluinod a index.html, e uma pasta css que está linkada com as pastas geradas por ia, pasta imagem onde tem as imagens geradas pela ia inicialmente.

- **Pasta modificada:** onde ficam os arquivos clonados pela ia para fazermos a edição, uma pasta css que está vinculada com os arquivos clonados para a modificação e uma pasta imagens de geradas por ia que usamos para ilustrar o site.

## Como executar
Abra usando link do vercel, ou pela pasta index.html.
